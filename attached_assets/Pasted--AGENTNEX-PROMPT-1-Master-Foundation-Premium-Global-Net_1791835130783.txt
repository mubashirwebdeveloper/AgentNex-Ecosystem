# AGENTNEX — PROMPT 1
## Master Foundation, Premium Global Network Experience & Production-Ready Architecture

You are an expert team consisting of a principal software architect, senior full-stack developer, SaaS product designer, UI/UX specialist, database engineer, accessibility specialist, and QA engineer.

Build a BRAND-NEW web application named **AGENTNEX** in this fresh Replit project.

This is Phase 1 of a much larger development roadmap. We will add advanced capabilities in separate numbered prompts. Your responsibility is to build an exceptional foundation that supports those later phases without forcing a complete rewrite.

**Project name:** AGENTNEX

**Tagline:** The Global Network for AI Agents, Businesses & People

**Product mission:** Create a trusted global digital infrastructure where individuals, companies, AI agents, suppliers, developers, and organizations can establish identities, discover one another, collaborate, automate workflows, and conduct permission-controlled business activities.

The attached design image is the primary visual direction. Study its styling, navigation, hierarchy, dashboard composition, global network aesthetic, and product modules.

IMPORTANT: The image represents the long-term product vision, not the functional scope of Prompt 1. Do not fabricate functionality, platform activity, statistics, customers, business listings, payments, or AI results to make the interface appear complete.

# 1. FUNDAMENTAL DEVELOPMENT RULES

1. This is a new application. Establish a clean architecture from the beginning.
2. Build real, working functionality for the features specifically assigned to Prompt 1.
3. Do not create decorative buttons pretending to work.
4. Do not use fake statistics or mock database records in the authenticated product.
5. Do not hardcode sensitive credentials or API secrets.
6. Do not implement incomplete AI functions that pretend to execute real AI tasks.
7. Separate frontend, backend, database, authentication, business logic, and reusable components cleanly.
8. All database operations must be associated with the correct authenticated user.
9. Handle loading, errors, empty states, and network failures.
10. All interfaces must work responsively on desktop, tablet, and mobile.
11. Add meaningful automated tests, run them, and report their results.
12. Preserve the architecture for future phases.
13. Do not implement later-phase features superficially just to make the application look finished.
14. Keep the interface premium, fast, accessible, and professional.
15. Favor correct, maintainable implementation over unnecessary visual complexity.
